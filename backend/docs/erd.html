Globe3D Backend — Entity Relationship Diagram

Django models across the players, geo, and quiz apps. (stats defines no models.)

Open this file directly in a browser. The diagram renders client-side via Mermaid.

    PLAYER ||--o{ ATTEMPT : "plays"
    DAILYQUIZ ||--o{ QUESTION : "contains"
    DAILYQUIZ ||--o{ ATTEMPT : "attempted in"
    ATTEMPT ||--o{ ANSWERRECORD : "records"
    QUESTION ||--o{ ANSWERRECORD : "answered by"

    PLAYER {
        int id PK
        string device_token UK "unique, indexed"
        string nickname
        string country
        string email UK "nullable, account upgrade"
        bool ads_removed
        string stripe_customer_id "billing milestone"
        datetime created
        datetime updated
    }

    COUNTRY {
        int id PK
        string cca2 UK "ISO-2"
        string cca3 "ISO-3"
        string name "restcountries common name"
        string mesh_name "frontend display name, indexed"
        float lat
        float lng
        string capital
        float capital_lat
        float capital_lng
        bool landlocked
        bool independent
        string region
        string subregion
        json continents
        json borders "list of cca3 neighbours"
        string flag_iso
    }

    DAILYQUIZ {
        int id PK
        date date UK "one per day, indexed"
        bigint seed "derives questions"
        datetime created
    }

    QUESTION {
        int id PK
        int quiz_id FK
        int index "unique per quiz"
        string type "name-country, identify-flag, etc."
        json payload "client-safe, no answer"
        json answer "server-only grading key"
        int points
    }

    ATTEMPT {
        int id PK
        int player_id FK
        int quiz_id FK "unique with player"
        int score
        int total_time_ms
        int current_index
        bool completed
        datetime started
        datetime finished "nullable"
    }

    ANSWERRECORD {
        int id PK
        int attempt_id FK
        int question_id FK "unique with attempt"
        json given
        bool correct
        int elapsed_ms "clamped"
        int elapsed_ms_raw "client-reported"
        datetime created
    }

Notes. COUNTRY is standalone reference data (no foreign keys); the quiz generators read it and reference countries by name inside QUESTION.payload/answer rather than via a DB relation. UK = unique constraint, PK = primary key, FK = foreign key. Django's built-in auth_*, django_*, and admin tables are omitted.
