# scratch/

Throwaway prototypes kept for reference only. **Not part of the runtime** — not
referenced by `index.html` and not deployed (see `docs/deployment/temp_deploy.md`).

- `test-load.html` — an early module-loading smoke page from the GLTF/`world.glb`
  era, before the globe moved to the baked `world-mesh.bin` pipeline.
- `wave_effect.html` — a standalone Vite/Django prototype exploring the flag
  wave-shader effect (note the leftover `{% static %}` template tags); the wave
  now lives in `js/features/flag-renderer.js`.

Safe to delete entirely if you don't want the history.
